## Version 0.3.6

### Improved
- **Info dialog** — added a **Changelog** button for quick access to the full release history, and a note that the app is tested on iPhone.

### Fixed
- **What's New dialog** — no longer collapses to zero height on iPhone.

---

## Version 0.3.5

### New
- **Help** — a new `?` button on the home screen opens a guide covering lists, packing, import/export, and more.
- **Example lists** — load four ready-made lists (Clothes, Utilities, Travel Documents, Full Packlist) straight from the Help dialog to get started quickly.
- **What's New dialog** — on first launch after an update, a dialog shows only the releases you have not seen yet. A **Show full changelog** button at the bottom expands the full history.

### Improved
- **Install banner** — Mac and Windows are now detected separately, with tailored instructions for each platform. Desktop users also see iPhone installation steps alongside the desktop steps.

---

## Version 0.3.3

### New
- **Export format** — packing lists can now be exported in a new portable format, making it easy to share or back up your data.

### Improved
- **Pack button** — an additional pack button is now available directly on the list screen for quicker access.
- Various bug fixes and stability improvements.

---

## Version 0.3.1

### New
- **Filter done items** — toggle the visibility of checked-off items to keep your view focused on what's left to pack.
- **Drag & drop reordering** — rearrange items and lists by dragging them into the order that makes sense for you.
